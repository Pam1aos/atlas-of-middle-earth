## 校验项

脚本在生成阶段执行以下检查，任一非零都会写进 `stats.json` 并在 `/about` 展示：

1. **关系端点有效性**：两端 slug 必须存在于实体表；当前 0 条失效。
2. **标题唯一性**：以标题作为页面路径，重复即冲突；当前 0 条重复。
3. **图片引用完整性**：实体引用的 WebP 必须存在于 `public/images`；当前 0 条缺失。
4. **摘要完整性**：28 个条目无法自动切出摘要（多为纯列表页），站点在这些条目上不显示摘要。
5. **来源完整性**：全部条目都保留了原站链接（0 条缺失）。

## 已知的数据缺口

- **无坐标**：原站不含经纬度，因此不做地图，只用「地区 → 地点」层级。
- **缺图 3,784 条**：原站这些条目本身没有插图（音乐曲目、书信、日期页占据多数）。
- **年代精度**：多数事件只有年份；只有 30 余条能精确到月日。
- **类型归类**：实体类型按章节 + 分类关键词推断，少数条目（如「维林诺」被归为势力）存在主观判断。
- **改编与原著**：影视改编条目的字段来自原站对应页面，未与原著设定合并，也未标注冲突。
